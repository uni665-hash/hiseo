📱 카카오톡 알림 설정이 필요합니다
  1. developers.kakao.com 에서 앱 생성
  2. REST API 키 복사 → .env 에 KAKAO_REST_API_KEY= 추가
  3. 플랫폼 → Web → 사이트 도메인 http://localhost:3000 등록
  4. 아래 버튼으로 카카오 로그인

카카오톡 연결하기
📋 노션 태스크 DB 설정이 필요합니다
  1. 노션에서 페이지를 열고 "..." → "연결 추가" → "hiseo" 선택
  2. PowerShell에서: node setup-notion.js 실행
  3. 출력된 NOTION_TASK_DB_ID=xxx 를 .env 에 추가
  4. 서버 재시작: npm start
